# Recursion `0.2.0-alpha.2`

`0.2.0-alpha.2` is the stabilized Connection Profile release contract for the Recursion pre-alpha extension.

## Contract

- Utility and Reasoner model work uses SillyTavern Connection Profiles only. Recursion does not own endpoint, credential, or provider-specific setup fields.
- Profile certification records real connectivity, structured-output, Segmented, and Fused behavior. Auto routing uses only current healthy evidence.
- Generation policy remains independent from sampler settings. Provider lanes expose compact derived readiness and capability states.
- Segmented batches settle each card slot independently and preserve successful siblings when one request fails.
- Fused preserves the original provider failure code through fallback. `RECURSION_FUSED_ZERO_USEFUL_CARDS` is reserved for a successful response whose parsed bundle contains no useful cards.
- Claude tool-use responses expose object-valued `content[].input` as structured data before schema validation.

## Verification

The alpha gate checks source, manifest, persisted runtime version, release indexes, normative Connection Profile guidance, and focused Claude, batch-isolation, and Fused regression coverage. The offline suite and alpha gate are the release evidence for this source tree.
